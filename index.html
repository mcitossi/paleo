Heavy Duty

Allenamento

Solo pesi liberi. La lat machine e i cavi del functional trainer sono fuori uso. Tre schede a rotazione, una seduta ogni 2-3 giorni. Nei giorni senza pesi, due camminate da 40 minuti.

Regole Heavy Duty
  • 1 serie di riscaldamento leggera, poi 2 serie allenanti.
  • Le serie allenanti arrivano al cedimento tecnico. Squat e stacco rumeno: fermati una ripetizione prima.
  • Cadenza: circa 2 secondi su, 3-4 secondi giù.
  • Recupero 2 minuti.
  • Quando chiudi il massimo delle ripetizioni, la volta dopo alza il peso.
  • La seduta dura circa 40 minuti.

Fuori casa

Quando non puoi pesare. Una scelta semplice vale più di un pasto saltato. Le quantità sono a occhio.

Proteine

Un palmo di carne o pesce, oppure 3 uova. Chiedi la cottura semplice, senza panatura.

Carboidrati

Un pugno di riso, cous cous o farro già cotti. A cena, se non c’è il cereale, due fette di Wasa oppure una porzione di ceci o fagioli.

Verdure

Un contorno abbondante. Meglio cotte. Sale poco.

Olio

Condimento a parte. Aggiungi tu circa un cucchiaino, a crudo.

Pranzo fuori

Carne o pesce alla griglia, riso o cous cous o farro, verdure, un filo d’olio a parte. Nei giorni di allenamento la porzione di cereale è un po’ più grande.

Cena fuori

Pesce, verdure cotte, poco cous cous oppure Wasa, ceci o fagioli. Olio a parte, circa un cucchiaino.

Spuntino

Yogurt greco 0% e un frutto. Nei giorni di allenamento, a metà mattina, aggiungi la whey se ce l’hai con te.

Storico

Peso, pressione, acqua e caffè giorno per giorno. Tocca una riga per aprire quella data.

Backup sul dispositivo

Esporta tutto il diario in un file JSON con la data nel nome. L’importazione unisce i giorni: stessa data nel file sostituisce quel giorno, gli altri restano. Il token GitHub non entra nel file.

Salvataggio su GitHub

Il repository mcitossi/paleo è pubblico. Peso, pressione e il diario non vanno mai caricati lì. Crea un repository privato chiamato paleo-dati. Poi crea un token fine-grained con accesso solo a quel repository e permesso Contents: Read and write. Il token resta solo su questo iPhone.
